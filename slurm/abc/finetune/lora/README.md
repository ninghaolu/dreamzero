# ABC LoRA jobs

Place future ABC LoRA Slurm recipes here. There is currently no ABC LoRA Slurm
job: the shared ABC launcher and its preflight require full finetuning.

The existing [DROID LoRA training script](../../../../scripts/train/droid_training_lora.sh)
is a separate dataset recipe, not an ABC job. Adding ABC LoRA support requires
an appropriate launcher and validation before a Slurm recipe can be used here.
